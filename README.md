# Airlines_Project_postgresql
A business-driven Airline Flight Operations Analytics project built using PostgreSQL (PL/pgSQL), analyzing route performance, flight frequency, cancellations, and fare behavior through real-world SQL queries. A recruiter-ready aviation data analyst portfolio project with query execution screenshots.
Problem: Airlines operate multiple flights on the same routes, but lack visibility into operational efficiency and fare consistency. This project was built to analyze flight frequency vs ticket pricing and log cancelled flights automatically when deleted from the main table.
My Role: Data preparation and SQL analysis for aviation insights using PostgreSQL (PL/pgSQL).
Calculated how often each airline flies a route
Compared fare behavior to observe pricing trends
Built a DELETE trigger to auto-store cancelled flights into a log table
Added indexing on Airline ID to test query performance improvement
Extracted month names from flight_date for seasonal analysis
